### Decisions ratified
- [x] **Deprecated API surface → keep.** The 2026-07-28 `schema.ts` still defines
  all 21 (`@deprecated`, SEP-2577 12-month retention); mocapi-model mirrors it 1:1
  (ADR-0014). Removing would make mocapi a less-faithful 2026-07-28 impl.
- [x] **ripcurl dependency → keep.** It's mocapi's JSON-RPC engine (dispatch +
  routing + message model), 35 files / 7 modules. Not a candidate for removal.
